# Divergencia respecto de upstream

Lista de revisión de cada fusión con `upstream` (T3 Code, `github.com/pingdotgg/t3code`). Cada archivo de upstream que Earlyscript modifica aparece aquí con sus líneas y su motivo. Las líneas corresponden al commit en que se introdujo el cambio; tras una fusión, buscar el enganche por su texto (`earlyscriptFlags` o `EarlyscriptAnalytics`).

Los archivos propios de Earlyscript no se listan como divergencia, pero se nombran al final para ubicarlos.

## Banderas de funciones (rama `es/telemetry-flags`, 30 de octubre de 2026)

Banderas en `packages/shared/src/earlyscriptFlags.ts`. Todas valen `false` por defecto. `EARLYSCRIPT_FLAG_<NOMBRE>=1|0` (también `true|false`) cambia una para pruebas; por ejemplo, `EARLYSCRIPT_FLAG_TELEMETRY=1`. En la web, el valor se fija al compilar o al arrancar Vite.
